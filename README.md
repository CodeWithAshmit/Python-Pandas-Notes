# Pandas Notes & Practice 📊

A collection of Jupyter notebooks covering the fundamentals of **Pandas in Python**, created for learning, practicing, and revising essential data manipulation and analysis techniques.

This repository contains structured notes and practical examples to build a strong foundation in data analysis using Pandas.

## 📚 Topics Covered

### 1. Series
- Introduction to Pandas Series
- Creating Series from different data types
- Indexing and accessing elements
- Basic Series operations

### 2. DataFrames
- Creating and understanding DataFrames
- Selecting rows and columns
- Indexing and filtering data
- Inspecting datasets using common Pandas methods

### 3. Missing Data
- Identifying missing values
- Handling null values using `isnull()` and `notnull()`
- Removing missing data with `dropna()`
- Filling missing values with `fillna()`

### 4. Merging, Joining & Concatenation
- Combining multiple DataFrames
- Merging datasets using common columns
- Joining DataFrames using indexes
- Concatenating rows and columns

### 5. GroupBy & Aggregation
- Grouping data using `groupby()`
- Applying aggregate functions
- Calculating sum, mean, count, minimum, and maximum
- Analyzing grouped data

### 6. Pivot Tables
- Creating pivot tables with `pivot_table()`
- Summarizing large datasets
- Aggregating values across multiple categories
- Organizing data for analysis

### 7. Operations
- Applying operations to Series and DataFrames
- Sorting and ranking data
- Using functions such as `apply()` and `map()`
- Performing common data manipulation tasks

### 8. Countries Dataset
- Exploring country-related data using `Countries.csv`
- Practicing data selection, filtering, and analysis

### 9. Feature Extraction
- Extracting useful information from existing columns
- Creating features from raw data
- Preparing data for further analysis

### 10. Anime Dataset
- Exploring anime-related data using `anime.csv`
- Practicing filtering, grouping, and aggregation
- Applying Pandas techniques to datasets
